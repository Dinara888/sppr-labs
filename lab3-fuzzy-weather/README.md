# Лабораторная работа №3. Нечёткая экспертная система анализа погоды

Программа анализирует погоду в Казани, Москве и Санкт-Петербурге. Текущие данные
берутся из OpenWeatherMap, а исторические из архива meteo.ru в папке `data/`.
Дальше программа считает сезонные нормы, выполняет нечёткий вывод по Мамдани
(scikit-fuzzy), ищет аномалии и формирует рекомендации.

## Структура

| Файл | Этап |
|------|------|
| `weather_data.py` | 1–3: OpenWeatherMap, загрузка архива, сезонные нормы |
| `linguistic.py` | 4: числа в лингвистические переменные (с учётом города и сезона) |
| `fuzzy_system.py` | 5: система Мамдани (антецеденты, консеквент, функции принадлежности, правила) |
| `analysis.py` | 6: аномалии (z-оценка) и рекомендации |
| `plots.py` | 7: графики и таблицы |
| `main.py` | точка входа |
| `data/wr316844.txt` | суточные данные: индекс ВМО; год; месяц; день; T средняя; осадки |

## Запуск

```bash
pip install -r requirements.txt
cp config.ini.example config.ini      # Windows: copy config.ini.example config.ini
# вписать ключ OpenWeatherMap в строку api_key = ...
python main.py                        # полный анализ
python main.py --history-only         # только история, нормы и графики (ключ не нужен)
```

Новый ключ OpenWeatherMap активируется в течение 10–120 минут после регистрации.

## Результаты (папка `results/`)

* `seasonal_norms.csv`, `table_norms.png`: сезонные нормы за 2015–2024 гг.;
* `seasonal_profiles.png`: температура (±σ) и осадки по сезонам;
* `trends.png`: многолетний ход среднегодовой температуры;
* `mf_<город>.png`: функции принадлежности для текущего сезона;
* `results.csv`, `table_results.png`, `current_vs_norm.png`: текущий анализ.
