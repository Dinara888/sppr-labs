## Как запустить

**Prolog-работы.** Нужно установить [SWI-Prolog](https://www.swi-prolog.org/Download.html) или открыть
[SWISH](https://swish.swi-prolog.org/). Затем загрузить файл командой `?- [weather].` и выполнить
запросы, приведённые в комментариях в конце файла. Протоколы выполнения лежат в папках `output`.

**ЛР №1 и ЛР №3.** Нужен Python 3. Порядок запуска:
1. Скопировать `config.ini.example` в `config.ini` и вписать свой API-ключ.
2. Запустить `run.bat` (Windows) или выполнить:
   ```
   pip install -r requirements.txt
   python main.py
   ```

Файлы `config.ini` с личными ключами в репозиторий не загружаются (см. `.gitignore`).
